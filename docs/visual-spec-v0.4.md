# 《雾铃小镇》v0.4 视觉规范

状态：阶段 0 定稿 / 阶段 1B 桥边黄昏分层样片完成 / 阶段 2A 地形材质完成 /
阶段 2B 地标、剧情道具与河岸完成

## 1. 不可变内容

- 保留 `18 × 14` 地图、全部碰撞格、NPC 坐标、互动 ID、七天剧情、存档格式、键盘与触屏操作。
- 原生画布为 `576 × 448`，玩法仍使用 `288 × 224` 逻辑坐标；渲染层以 `2×` 映射，因此一个逻辑图块对应原生 `32 × 32` 像素。
- 素材必须是原创 PNG；封面只作气氛参考，不裁切或描摹成游戏素材。
- 样片以“春 6 三盏桥灯试亮后的黄昏”为标准状态，不增加地图、角色或剧情。

## 2. 像素与构图

| 项目 | 规格 |
|---|---|
| 地图 | `18 × 14` 逻辑格 |
| 原生画布 | `576 × 448` |
| 环境图块 | `32 × 32` |
| 玩家 / 阿栀 | 可见主体约 `24–30 × 36–40`，精灵单元 `40 × 48` |
| 脚点 | 每格底边中心，必须落在原生整数像素 |
| 桌面显示 | 基础 `576px`；宽屏为原生画布整数 `2×` 的 `1152px` |
| 手机显示 | 主要断点使用 `288px`，即原生画布精确 `1/2` |
| 线条 | 外轮廓 1–2 原生像素；不用纯黑，使用材质深色 |
| 纹理 | 每个材质控制在暗 / 中 / 亮三阶，少量黄昏轮廓光 |

移动插值、阴影、交互框和精灵目标矩形必须先对齐原生像素。禁止连续小数 `bob` 或 `sway`；环境动画使用离散整数帧。

| 灯金 | `#F4C467` | 灯芯、铃面、水面最亮反光 |

## 4. 人物辨识

- 玩家：苔绿圆帽、深青背心、赭黄围巾、棕色斜挎包；不再与沈砚共用草帽轮廓。
- 阿栀：梅紫双髻、珊瑚短衣、蜜金肩带；小个子、轻快、风吹时飘带先动。
- 林麦：发髻、米白围裙、红领巾、面包篮。
- 沈砚：高瘦、窄檐帽、靛蓝长衣、灯钩或铃绳。
- 许槐：宽肩、卷袖、木工围裙和腰锤。
- 秦婆婆：白发髻、微驼背、鼠尾草披肩、药草篮或手杖。

阶段 1B 为避免样片混用矩形占位，增加林麦、沈砚、许槐、秦婆婆的四方向静态图集；完整行走帧和专属动作仍留待阶段 2。

## 5. 动画

| 对象 | 帧与节奏 |
|---|---|
| 玩家行走 | 四方向 × 四帧；单格移动完整走完四帧 |
| 玩家 / 阿栀待机 | 两帧，约 `1.4 FPS` |
| 旧风铃 | 四帧，`5–6 FPS` |
| 布条 | 四帧，`4–6 FPS` |
| 水面与灯影 | 四帧，`4 FPS` |
| 灯火 | 熄灭 / 微光 / 点亮 / 呼吸四状态，最高 `6 FPS` |
| 花瓣 | 低密度、离散整数步进 |

启用“减少动态效果”时，环境固定在安全帧；移动、交互和剧情不得依赖动画结束事件。

## 7. 命名与图集

单帧规则：

```text
{类别}_{对象}_{动作或状态}_{方向或变体}_f{两位帧号}.png
```

图集规则：

```text
{类别}_{对象}_{动作}_{布局}_{帧数}_v{两位版本号}.png
```

类别使用 `chr`、`tile`、`prop`、`fx`、`ui`。方向使用 `n/e/s/w`；状态使用 `idle/walk/talk/lit/rain/dusk`。

示例：

```text
chr_player_walk_s_f00.png
chr_azhi_idle_e_f01.png
tile_water_dusk_a_f03.png
prop_windchime_old_sway_f03.png
fx_lamp_reflection_water_f02.png
ui_portrait_azhi_64.png
chr_player_walk_4dir_4f_v01.png
```

当前图集契约：

- 玩家：`40 × 48` 单元，行顺序 `n/e/w/s`，列为四步。
- 阿栀：`40 × 48` 单元，行顺序 `s/w/e/n`，列为四步。
- 四位村民样片：`40 × 48` 单元，行顺序 `s/w/e/n`，列依次为林麦、沈砚、许槐、秦婆婆。
- 阶段 2A 地形：`32 × 32` 单元，行顺序为草地 / 泥路 / 石广场 / 水面，每行四个变体。
- 阶段 2B 河岸：`32 × 32` 单元，`4 × 2` 布局，包含北岸、西岸、转角与桥口。
- 阶段 2B 地标：`192 × 160` 单元，面包房 / 桥梁各有 base 与 foreground。
- 阶段 2B 药草棚：`96 × 80` 单元，关闭 / 打开种子箱各有 base 与 foreground。
- 阶段 2B 剧情道具：`64 × 64` 单元，`4 × 3` 布局，包含公告板、白布桌与村口门状态。
- 桥边道具：`32 × 32` 单元；第 0–3 行依次为风铃、布条、灯笼、水面反光，列为四帧。
- 阶段 1B 场景：`576 × 448` 无人物背景层与同尺寸透明桥栏前景层，必须成对加载。
